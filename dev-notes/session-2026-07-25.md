# Session 2026-07-25

## Scope

Linux の画面暗転スクリプトを Wayland/GNOME に対応させ、使い方と開発記録を整備する。

## Decisions

- Topic: Wayland/GNOME での画面暗転
  - Decision: `blank` は Wayland + GNOME では Mutter の `PowerSaveMode=1` を `busctl` で設定し、X11 では従来どおり `xset dpms force off` を使う。
  - Rationale: `xset` は X11 専用であり、Ubuntu GNOME の Wayland セッションでは Mutter の D-Bus API が利用できるため。
  - Alternatives Considered: `wlopm` は wlroots 向けで GNOME には適さない。`PowerSaveMode=3` は復帰挙動がハードウェア依存のため採用しなかった。

- Topic: 画面暗転抑止
  - Decision: `awake` を常駐型スクリプトとして追加し、`gnome-session-inhibit --inhibit idle --inhibit-only` を管理する。
  - Rationale: 抑止はプロセスが終了すると解除されるため、スクリプトが実行中である間だけ有効にする必要がある。

- Topic: `awake` の表示
  - Decision: 起動時に停止方法を表示し、同じ行を ANSI エスケープで更新する。60秒未満は秒表示、60秒以降は10秒ごとに分とドットを更新し、10秒単位で `.` から `.....` まで表示して分が変わるとリセットする。
  - Rationale: 短時間は正確な経過秒を確認でき、長時間は表示を簡潔に保てる。

- Topic: Versioning and documentation
  - Decision: `blank --version` と `awake --version`（`-v` も可）で `0.1.0` を表示する。GitHub 用に英語の `README.md` と日本語の `README_ja-JP.md` を用意する。
  - Rationale: スクリプト単体でもバージョンを確認でき、利用者向け文書を言語別に分離できるため。

- Topic: License
  - Decision: Public Domain の意図を CC0 1.0 で示す。
  - Rationale: 単なる Public Domain 表記より、法域をまたいだ扱いを明確にしやすい。
